# Solastio Design System

## Visual Direction

Premium operational software: calm graphite text, warm paper backgrounds, restrained accents, strong data hierarchy, and minimal chrome.

## Tokens

| Token | Value |
| --- | --- |
| Font | Inter or system sans-serif |
| Numeric Font | Tabular system numerals |
| Background | `#f7f4ee` |
| Surface | `#fffdf8` |
| Text | `#171717` |
| Muted Text | `#6d6a63` |
| Border | `#ded8cc` |
| Primary | `#1d4f45` |
| Accent | `#b7791f` |
| Success | `#16794c` |
| Warning | `#a15c00` |
| Error | `#b42318` |

## Components

Build reusable primitives for buttons, inputs, selects, dropdowns, modals, drawers, tables, cards, tabs, badges, toasts, alerts, tooltips, pagination, date pickers, search, filters, skeletons, empty states, error states, and confirmation dialogs.
